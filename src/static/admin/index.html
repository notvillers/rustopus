Add a block

An IP value takes a single address or a CIDR range (203.0.113.0/24) when an abuser rotates within one network; both the proxy's X-Forwarded-For address and the connecting socket are checked, so a forged header does not walk past a block. An authcode is stored hashed — it is never written to disk or shown again, only its FFD3…0E37 mask.

Cache usage

Snapshots live in memory and are mirrored to disk. Memory answers queries; disk is what a snapshot falls back to when it is evicted or the server restarts, which costs well under a second instead of a full rebuild from the ERP.
